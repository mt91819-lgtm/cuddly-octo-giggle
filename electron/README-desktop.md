# نسخة سطح المكتب (Electron) — دليل التشغيل والبناء

تحوّل هذه الطبقة نظام الكاشير الحالي (HTML/JS) إلى **برنامج ويندوز مثبّت (.exe)**
يعمل **أوفلاين بالكامل** ويطبع **مباشرة بدون نافذة طباعة**:

- **طابعة الباركود (Zebra ZD410):** أمر **ZPL خام** يُرسَل مباشرة للطابعة → باركود حاد ومضبوط.
- **طابعة الإيصال (Fujitsu FP-2000):** طباعة **صامتة** للإيصال (العربية تُطبع سليمة 100%).

> النظام نفسه لم يتغيّر — أُضيفت طبقة Electron حوله، وعُدّل مسار الطباعة فقط
> ليطبع مباشرة عند التشغيل كبرنامج مثبّت (ويظل المتصفح يعمل كما هو لو فُتح في متصفح).

## المتطلبات (مرة واحدة على جهاز التطوير/الويندوز)
1. ثبّت **Node.js LTS** من https://nodejs.org
2. افتح موجّه الأوامر داخل مجلد المشروع.

## التشغيل للتجربة (بدون بناء)
```
npm install
npm start
```
سيفتح البرنامج في نافذة. جرّب البيع والطباعة.

## بناء ملف التثبيت (.exe)
```
npm install
npm run dist
```
سيظهر المثبّت داخل مجلد **`dist/`** (مثل `Cashier Pro Setup 1.0.0.exe`).
انسخه لأي جهاز ويندوز وثبّته — يعمل أوفلاين تمامًا.

## ضبط الطابعات داخل البرنامج
بعد التشغيل، روح **الإعدادات** → سيظهر قسم **«طابعات سطح المكتب»**:
- اختر **طابعة الملصقات** = Zebra ZD410.
- اختر **طابعة الإيصال** = Fujitsu FP-2000.
- لطباعة ZPL للملصقات: اضبط **طريقة الطباعة = «Zebra ZPL مباشر»**.
- احفظ، ثم استخدم **«طباعة ملصق/إيصال تجريبي»** للتأكد.

## نقل بياناتك من نسخة المتصفح (إن وُجدت)
- من نسخة المتصفح: **نسخة احتياطية (Export)**.
- في البرنامج المثبّت: **استيراد (Import)**.

## كيف تعمل الطباعة المباشرة؟
- الطباعة الخام (ZPL/ESC-POS) تُرسَل عبر واجهة ويندوز `winspool` باستخدام PowerShell
  (بدون أي وحدات native تحتاج بناء) — راجع `electron/print-raw.js`.
- طباعة الإيصال الصامتة تُرسم في نافذة مخفية وتُطبع بطول محتوى مضبوط — راجع `print:html` في `electron/main.js`.

## ملاحظات
- الطباعة الخام تعمل على **ويندوز** فقط (وهو هدفنا). على غير ويندوز تُستخدم الطباعة الصامتة.
- إن لم تُحدّد طابعة بالاسم، تُستخدم الطابعة الافتراضية في ويندوز.
